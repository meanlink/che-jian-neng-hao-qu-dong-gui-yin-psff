# 集团联合能耗归因（各厂原始日样本不出站）

在单机版「车间能耗驱动归因」（`backend/src/services/business.py`）之上，支持集团多厂
联合估计能耗驱动：各厂原始日样本不出站，独立站点之间只交换**数据汇总**
（充分统计量与留出误差），协调方聚合求解，保留原有时间留出与选参含义。
纯 Python 标准库实现，无第三方依赖，可完全在本地演练。

## 与单机版的语义对应

| 单机版 analyze() | 联合版 |
|---|---|
| 前80%记录训练、最后20%一次验证 | 开算冻结日期边界，按同一比例换算日期窗：训练窗天数=int(总天数×0.8)，其余为留出窗，仅验证一次 |
| 训练内3折 TimeSeriesSplit | 训练窗内按天数取同样的3段前向验证（test_size=训练窗天数//4，逐段扩窗） |
| 2..k个特征子集 × α∈{0.1,1,10}，CV RMSE最低 | 同一网格、同一顺序、同一平局规则，在聚合统计量上求CV RMSE |
| StandardScaler逐折独立拟合 + Ridge | 各折统计量上复现同一标准化（有偏方差、零方差取1）与岭求解（(ZᵀZ+αI)w=Zᵀ(y−ȳ)），系数还原原始单位 |
| 留出RMSE/R²，留出期目标恒定R²不可定义 | 各厂用全局系数本地算留出误差，汇总全局RMSE/R²，同一恒定判定阈值 |
| 最近14天均值基准、产量与运行小时同步缩放的情景 | 冻结边界最后14天为情景窗，同一缩放与同一组告警 |
| ≥70天、业务范围、日期唯一、目标无变化即拒 | 各厂本地执行同一校验；≥70天与目标方差在全局聚合后按同一阈值判定 |

单机版按记录序号切分，联合版按冻结日期窗切分；各厂在边界内逐日齐备时两者完全一致
（`merged_analyze` 单机对照实现与联合结果的逐位对拍见测试 `TestParity`）。

## 协议与可靠性

- **开算冻结**：参与厂、各厂样本版本（SHA256内容指纹）、日期边界与派生时间窗、
  选参网格全部写入清单并给出清单指纹；开算后样本版本不符的贡献一律拒收。
- **阶段屏障**：`train_stats`（训练统计汇总）→ `holdout_eval`（留出误差汇总）。
  同阶段各厂齐备才推进；缺席厂不按零计入，屏障等待并在页面标出缺席名单。
- **交换内容**：阶段一各厂提交训练窗累计充分统计量（样本数、特征/目标一阶二阶和、
  交叉和，共4个折边界）+ 情景窗统计 + 训练窗特征极值；阶段二提交本厂留出窗
  误差与目标汇总。任何原始日样本（日期-特征-电耗行）都不出站。
- **幂等与防串**：贡献按 `(运行, 阶段, 厂站)` 归键，聚合只对冻结参与厂全集做一次，
  结构上不存在重复累计；同序号同内容重试幂等接受，**同号异内容拒收**，
  内容指纹不符拒收；**旧阶段迟到回包按阶段栅栏拒收**，不串入当前阶段；
  全部变更持锁进行，并发推进与迟到回包不交叉污染。
- **中断恢复**：每次变更整体原子落盘（`--data-dir`）。厂站断线或协调服务中断后，
  用同一数据目录重启即恢复已确认阶段（快照不可变）；崩溃于屏障计算中的，
  `POST /api/runs/{id}/resume` 或启动时自动重放屏障判定补推进，不重复累计。
- **批准门**：各厂留出误差与全局系数齐备（两阶段快照齐全）才允许批准；
  批准前结果包一律 409（半成品不公开），批准后 `/api/runs/{id}/result` 开放分发。

## 快速开始（本地演练）

```bash
python -m federated.demo init --dir .demo/fed --sites 3     # 生成3厂演示CSV
python -m federated.demo up   --dir .demo/fed --port 8310   # 起协调方+3个厂站代理
python -m federated.demo run  --dir .demo/fed --port 8310   # 按已注册版本发起并冻结
```

页面 `http://127.0.0.1:8310/`：发起（冻结参与厂/版本/日期边界）、恢复
（单运行恢复与全部恢复）、看板（待汇总/待批准/已完成/失败）、运行详情
（各厂来源：阶段、序号、内容指纹、到达时间）、批准分发、结果包查看与下载。

## 演练入口

页面上可直接操作，也可用API：

| 演练 | 入口 | 预期 |
|---|---|---|
| 厂站断线 | 厂站表格「断线30秒」→ `POST /api/sites/{id}/drill/disconnect` | 屏障等待该厂，缺席不当零；恢复后自动补齐 |
| 迟到回包 | 运行卡片「迟到回包」→ `POST /api/runs/{id}/drill/late` | 旧阶段重投 → 409 `stage_closed`，快照不变 |
| 同号异包 | 运行卡片「同号异包」→ `POST /api/runs/{id}/drill/conflict` | 同序号异内容 → 409 `seq_conflict` |
| 协调服务中断 | 杀掉 `federated.coordinator` 进程后用同一 `--data-dir` 重启 | 已确认阶段保留，屏障继续，重试不重复累计 |

## API 摘要

- `POST /api/runs` 发起并冻结（params/boundary/participants）
- `GET /api/overview`、`GET /api/runs/{id}` 看板与详情（各厂来源）
- `POST /api/runs/{id}/contributions` 厂站贡献（幂等+栅栏）
- `GET /api/runs/{id}/brief?site_id=` 厂站轮询视图（含阶段二全局系数简报）
- `POST /api/runs/{id}/resume`、`POST /api/admin/recover` 恢复
- `POST /api/runs/{id}/approve`、`GET /api/runs/{id}/result` 批准与分发
- `POST /api/runs/{id}/fail` 厂站上报本地校验失败（留来源）
- `POST /api/sites/register`、`GET /api/sites` 厂站注册与心跳

## 边界与限制

- 本模块为本地演练实现：未接入主平台的认证/审计，生产化时应挂在既有
  认证与审计之后；数值采用float64中心和形式，更大规模可换平移/缩放累加器。
- 演示数据为固定随机种子模拟数据，不能作为实际生产决策证据。
